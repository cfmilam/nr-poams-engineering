# Receiver Stage 0 — Local Source Characterization

## Program question

Does changing a remote completion constraint produce a bounded, reproducible change in a fully instrumented local source record after ordinary propagation, storage, coupling, switching, timing, and software pathways are measured?

Stage 0 does not test signalling capacity, teleblocking, no-transit ontology, or backwards signalling. It characterizes the source and earns—or refuses—the entry ticket to Stage 1.
