# Receiver Stage-1 dependency and source ledger

## Existing basis

The current Receiver work already names intended, detuned, unmatched, frequency-matched clone, multiple-load, sink-absent and signature-reversal controls, and separates endpoint sensitivity from later information claims. The new Stage-0 package turns its local-source skeleton into a reference build. This package narrows Stage 1 to controlled coupling and deliberately moves all symbol/capacity work to Stage 2.

## Required real Stage-0 values

- exact M0/M1 hashes and pass report;
- selected source, line, return, grounding and termination hardware;
- primary native source observable/reduction and its noise/correlation;
- source command, bandwidth, filters, windows and blank/open envelopes;
- empirical transfer function and covariance;
- common-clock fixed delays, drift, jitter and latency uncertainty;
- B0/B1/B2 manifests and closed energy/storage account;
- nuisance transfer functions, veto limits and unresolved anomalies;
- smallest effect/equivalence region, block/washout/stop rules;
- held-out geometry and physical-repeat results.

Without these, this package remains conditional and no numerical threshold is defensible.

## Additional blockers

1. Intended sink technology and native signature vector are not selected.
2. No characterized dummy or independent clone exists.
3. No demonstrated geometry reversal preserves ordinary loading and cable strain.
4. No parasitic sink census volume or sensitivity has been defined.
5. No M0 Stage-0 pass exists; therefore no Stage-1 acquisition is authorized.
