# Receiver Stage-1 functional bill of goods

Stage-0 qualified hardware is inherited unchanged unless a new branch repeats qualification.

| Group | Addition | Functional specification |
|---|---|---|
| Intended sink | Characterized sink article/network | Stable multidimensional signature; independent state readout; locally measurable impedance, resonance, phase, linewidth, dissipation and temperature |
| Detuning | Controlled tuning element | Sweeps declared coordinate without changing unrelated load/heat beyond measured bounds |
| Dummy | Matched dummy network/article | Matches ordinary impedance, command burden, heat and geometry while omitting declared signature |
| Clone | Independent frequency-matched article | Matches resonance/gross loading; differs in at least one preregistered signature coordinate |
| Fixture | Sink-absent reference fixture | Same mount/cables/actuator burden with complete parasitic inventory |
| Geometry | Reversible indexed mount | Repeatable rotation/translation/handedness transform with metrology and invariant cable strain where claimed |
| Actuation | Isolated sink-state controller | Sham mode; raw command/acknowledgement; independent physical witness; reaction and leakage monitored |
| State readout | Independent sink sensors | Measures every signature coordinate used in classification; does not derive state from source output |
| Network metrology | VNA/impedance/time-domain capability | Maps intended, dummy, clone and detuned states at common reference planes |
| Multiple-sink rig | Switchable secondary load fixture | Tests competition/superposition without changing undocumented paths |
| Parasitic census | Movable calibrated loads/absorbers/probes | Maps unintended sink sensitivity through declared volume/routes |
| Environment | Additional sink thermometry, field, strain and vibration channels | Resolves actuator and article nuisance transfer |
| Timing | Sink witness hardware timestamp | Same common clock; independently calibrated fixed delay/jitter |
| Custody | Expanded simultaneous DAQ/storage | Retains source, sink, route, commands, witnesses and environment without multiplexing ambiguity |

## Values inherited from Stage 0, not invented here

Source waveform and IDs; primary channel/reduction; bandwidth; clock tolerance; B0/B1/B2 crossings; baseline/open bounds; artifact limits; line geometry; sensor ranges/rates; settling/washout; calibration covariance; smallest effect/equivalence region; and maximum blocks. Stage 1 adds numerical sink-signature tolerances, detuning grid, clone/dummy equivalence bounds and geometry transforms only after local characterization.
