# Rate-of-Time Material-State

## Program question

Can a reversibly prepared, independently witnessed material state produce a repeatable fractional-rate component shared by two dissimilar clocks after ordinary clock shifts, reference motion, transfer-path effects, thermal response, strain, magnetic response, vibration, and leakage are directly calibrated?

This program is deliberately able to conclude that every observed response is ordinary local spectroscopy. A common residual is not automatically a change in time.
